# 채팅방 웹소켓(WebSocket) API 명세서
# ==============================================================================
# 통신 프로토콜: WebSocket (로컬 환경은 ws://, 배포 환경은 wss://)
# 접속 엔드포인트: /ws/chat/{roomId}/
# 인증(Auth): 현재 장고(Django) 기본 세션/미들웨어 방식 사용.
#             (추후 JWT 토큰 방식 도입 시 백엔드 미들웨어 수정 필요)
# ==============================================================================

--------------------------------------------------------------------------------
1. 클라이언트 -> 서버 (메시지 전송)
--------------------------------------------------------------------------------
사용자가 채팅을 입력하고 '전송(Send)' 버튼을 누를 때 서버로 발송됩니다.

* 데이터 형식: JSON
* 페이로드 구조:
  {
    "username": "문자열 (보내는 사람의 닉네임 또는 ID)",
    "message": "문자열 (입력한 채팅 내용)"
  }

* 전송 예시:
  {
    "username": "testuser1",
    "message": "오늘 너무 행복해!"
  }

--------------------------------------------------------------------------------
2. 서버 -> 클라이언트 (메시지 브로드캐스트 및 감정 분석)
--------------------------------------------------------------------------------
서버가 누군가로부터 메시지를 받으면, 같은 방에 있는 모든 유저에게 메시지를 뿌려줍니다.
⚠️ 백엔드 필수 주의사항: 백엔드는 메시지를 단순 전달만 하지 말고, 반드시 AI 감정 분석을 
거친 뒤 'emotion'이라는 키값(CSS 클래스명)을 추가해서 브로드캐스트해야 합니다.

* 데이터 형식: JSON
* 페이로드 구조:
  {
    "username": "문자열 (보낸 사람의 닉네임)",
    "message": "문자열 (채팅 내용)",
    "emotion": "문자열 (프론트엔드와 약속된 감정 CSS 클래스명)"
  }

* 수신 예시:
  {
    "username": "testuser1",
    "message": "오늘 너무 행복해!",
    "emotion": "emotion_happy"
  }

* 프론트엔드에 맵핑되어 있는 감정(emotion) 클래스 목록:
  - emotion_happy (행복)
  - emotion_sad (슬픔)
  - emotion_angry (분노)
  - emotion_fear (공포/두려움)
  - emotion_surprise (놀람)
  - emotion_disgust (혐오/불쾌)
  - emotion_neutral (중립/평범)
