--------------------------------------------------------------------------------
1. 방 목록 조회 및 검색
--------------------------------------------------------------------------------
방 목록 페이지 로드, 페이지 번호 클릭, 또는 검색 실행 시 호출됩니다.

* URL: /api/rooms
* Method: `GET`
* 쿼리 파라미터 (Query Parameters):
  - page (정수, 필수): 현재 페이지 번호 (1부터 시작).
  - limit (정수, 필수): 한 페이지당 불러올 방의 개수 (프론트엔드에서 20을 보냅니다).
  - search (문자열, 선택): 방 제목을 필터링할 검색어.

* 요청 예시 (Request Example):
  GET /api/rooms?page=1&limit=20&search=Emotion

* 성공 응답 (Success Response):
  - HTTP 상태 코드: 200 OK
  - 본문 (JSON):
    ⚠️ 중요: 프론트엔드에서 방 목록을 그리기 위해 'totalRooms'와 'rooms'라는 정확한 키값이 필요합니다. 
    'rooms' 배열 안의 객체는 'id', 'title', 'host', 'count', 'max' 키를 반드시 포함해야 합니다.
    {
      "totalRooms": 45,
      "rooms": [
        {
          "id": "room_123",
          "title": "행복한 채팅방",
          "host": "User_42",
          "count": 3,
          "max": 10
        }
      ]
    }

* 에러 응답 (Error Response):
  - HTTP 상태 코드: 500 Internal Server Error (또는 400 Bad Request 등)
  - 본문 (JSON):
    {
      "message": "방 목록을 불러오는 데 실패했습니다."
    }
