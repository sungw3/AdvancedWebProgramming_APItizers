--------------------------------------------------------------------------------
1. 새 채팅방 생성
--------------------------------------------------------------------------------
사용자가 'Create & Enter' 버튼을 눌러 폼을 제출할 때 호출됩니다.

* URL: /api/rooms
* Method: `POST`
* 헤더 (Headers):
  - Authorization: Bearer <accessToken>
* 요청 본문 (JSON Body):
  - title (문자열, 필수): 채팅방 제목. (프론트엔드에서 양옆 공백 제거 후 전송)
  - subtitle (문자열, 선택/Null 허용): 방의 부제목 또는 간단한 설명.
  - maxParticipants (정수, 필수): 최대 허용 인원 수 (2~10).
  - isPrivate (불리언, 필수): 비밀번호가 설정된 비밀방이면 true, 공개방이면 false.
  - password (문자열 또는 Null, 필수): isPrivate이 true일 경우 방 비밀번호, false일 경우 null.

* 요청 예시 (Request Example):
  {
    "title": "오늘 하루 어땠나요?",
    "subtitle": "따뜻하고 편안한 분위기",
    "maxParticipants": 6,
    "isPrivate": true,
    "password": "roompassword123"
  }

* 성공 응답 (Success Response):
  - HTTP 상태 코드: 201 Created (또는 200 OK)
  - 본문 (JSON):
    ⚠️ 중요: 프론트엔드가 방 생성 후 해당 채팅방으로 이동하기 위해 'roomId'라는 정확한 키값을 응답으로 받아야 합니다.
    {
      "roomId": "생성된_방의_고유_ID_문자열"
    }

* 에러 응답 (Error Response):
  - HTTP 상태 코드: 400 Bad Request / 401 Unauthorized 등
  - 본문 (JSON):
    {
      "message": "방 생성에 실패했습니다. 다시 시도해 주세요."
    }
